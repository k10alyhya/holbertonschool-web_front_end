# HTML Advanced

Building **Techium**, a digital agency website, using semantic HTML5 only (no CSS).
The project covers page structure, semantics, accessibility, media and a complete styleguide.

## Learning Objectives

- Create the skeleton of an HTML5 page (`doctype`, `head`, meta tags, favicons)
- Use semantic tags: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Use headings in hierarchical order (`h1` to `h6`)
- Know when to use `div` vs `span`
- Create lists (`ul`, `ol`, `dl`) and tables (`caption`, `thead`, `tbody`, `scope`)
- Understand media formats (SVG, PNG, JPG, GIF) and use `img` with proper `alt`
- Embed video, audio and external content (`video`, `audio`, `iframe`)
- Write accessible markup (alt text, titles, scope attributes)

## Requirements

- All files are interpreted by modern browsers
- Code should be W3C compliant (unless stated otherwise)
- Company name used across pages: `Techium`
